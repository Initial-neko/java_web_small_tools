## 固定技术约束

### Java

    Java 8

不要因为上游最新版已经升级 JDK 就直接跟随最新版。

### JSON

统一：

    com.alibaba:fastjson 1.x

本仓库不为这些工具再引入新的 JSON 框架。

当前锁定：

    fastjson 1.2.84

JSON 样本转 Entity 的类型推断和代码生成后续围绕 Fastjson 的 JSONObject/JSONArray 做。

### MyBatis Generator

锁定：

    org.mybatis.generator:mybatis-generator-core:1.4.2

原因：

- Java 8 可运行
- 满足经典 MyBatis Model / Mapper / XML 生成
- 2.x 不适合当前 Java 8 基线

### JDBC Driver

不打进 toolbox.jar。

运行时外置：

    drivers/

至少正式验证：

- 达梦 DM8
- Oracle

### SQL Parser

达梦 SQL 不自己写 Lexer/Parser。

锁定候选：

    com.alibaba:druid:1.2.28

Druid 负责 SQL -> AST；Toolbox 负责 AST -> LineageGraph。

## 开发顺序

### Batch 1（当前 PR）

- Fastjson 依赖锁定
- 现有 JSON 工具迁移到 Fastjson
- MyBatis Generator 后端封装
- Oracle / DM 外置驱动
- Web 表单
- 内网离线文档
- Notebook
- Batch lineage 设计基线

### Batch 2

Entity Generator：

    Fastjson JSON
       -> EntitySchema
       -> Normal Java / Lombok / Mapping Code

同时接：

    Excel -> EntitySchema

### Batch 3

SQL Analyze Core：

    Druid DM Parser
       -> tables / columns / read-write
       -> LocalLineageResult

先建立真实 DM SQL corpus。

### Batch 4

Batch Lineage：

    N SQL
      -> fault-isolated parse
      -> local lineage
      -> global aggregation
      -> JSON / Excel export
      -> failed SQL corpus

## 不做的事情

当前阶段不要：

- 自研 SQL grammar
- 把 Oracle/DM JDBC Jar 提交 Git
- 自动扫描整个数据库并生成所有表
- 引入 Jupyter/Python 作为 Notebook 运行时
- 为每种数据库复制一套 Entity Generator
- 为 JSON 功能切换到另一套 JSON 框架

## 验收规则

每个新增工具至少需要：

1. Java 8 编译通过
2. 无网络运行路径
3. 文档写明依赖版本
4. 输入错误可读
5. 单项失败不破坏其他工具
6. Oracle/DM 相关能力必须有真实环境回归记录
