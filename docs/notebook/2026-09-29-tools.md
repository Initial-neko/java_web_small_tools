## 明确不做 / 暂缓

- 字段级血缘：当前不需要。
- 专门的 INSERT ... SELECT 血缘能力：DM 当前场景不需要，不作为验收项。
- DM/Oracle 真实数据库验收：由用户在内网完成。
- 自动捆绑 DM/Oracle JDBC Driver：不做，避免版本和分发问题。
- 自研 SQL grammar：不做。
- Jupyter/Python Notebook Runtime：不做。
